How claiming works

  1. Fork free-domain-name/registry.
  2. Create {{path}} with this record:
{{json}}

GitHub normally keeps this formatting in the new-file editor. If it flattens the JSON, use Copy JSON and paste the formatted version.

An IP address is enough — like an A record for HTTP. No domain or DNS record is needed. Replace 203.0.113.10 with your server's public IP (add :port if needed). Keep this an origin: no path, query or fragment — the browser appends the visitor's path. Use http:// for a bare IP; HTTPS certificates are issued to names, not addresses.

CI checks the shard path, the four fields, the target URL and the TTL. When the target is an IP, the browser sends the free name as Host, so one address can serve many names.
