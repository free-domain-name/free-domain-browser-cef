on Chromium itself.

The Free Domain Browser checks the community registry before public DNS and asks you when a name exists in both. This build keeps that behaviour and swaps the system web view for the Chromium Embedded Framework, so every page is rendered by the same engine everywhere.

Written in Rust on top of cef-rs, with a fixed HTML chrome bar above the page, tabs that keep their own title, and the community chat next to the tab you are reading.

What it does

The browser, feature by feature.

◎

Registry first, DNS second

Names are looked up in the community registry before public DNS. When a name exists in both, the browser asks and remembers the answer for the session, so you decide once.

▤

Tabs that behave

Dynamic tabs with their own titles, closing and shortcuts. The address bar and the window title follow the tab you are looking at, with back, forward, reload and home within reach.

◇

Chrome as plain HTML

The bar above the page is one fixed HTML view, with a security indicator, a new tab page and the settings overlay. Skins, compact density and the light and dark themes apply to it.

◐

Chat next to the page

The community chat opens in a 420 px side panel that follows the active tab, with a compact drawer for narrow windows. It talks to the ported iroh service over the public relay.

⌘

Menus on every platform

A native menu bar on macOS and Windows, and a menu window on Linux, where CEF draws its own window. Press F10 or Alt+F to open the menu.

↺

Errors worth reading

Retry error pages, fdn:// links handled inside the browser, and community reviews that open in a reusable review window of their own.

Preview packages

One command, three platforms.

Every release carries a checksums.txt.

macOS

Portable zip with the app bundle, and a disk image with it.

FreeDomainBrowser-CEF.zip FreeDomainBrowser-CEF.dmg

Linux

Tarball that starts through a launcher, and a Debian package that keeps the sandbox.

FreeDomainBrowser-CEF-linux-x86_64.tar.gz FreeDomainBrowser-CEF-linux-x86_64.deb

Windows

Portable zip, and an NSIS setup when the tool is available.

FreeDomainBrowser-CEF-windows-x64.zip FreeDomainBrowser-CEF-windows-x64-setup.exe

The packages are ad-hoc signed at best: they are not notarized and not signed with a Developer ID or an Authenticode certificate. macOS and Windows will ask you to confirm the first launch. If you want a signed, installer-first build, take the Tauri release.

Build it yourself

Rust and CEF.

⌘ 
git clone https://github.com/free-domain-name/free-domain-browser-cef
cd free-domain-browser-cef
cargo run

CMake and Ninja, plus the platform toolchain (Xcode command line tools, GCC/GTK3/NSS or Visual Studio C++ build tools). The pinned CEF distribution is downloaded on the first build. The build and the smoke test also run in a container: docker build -f Dockerfile.linux -t fdb-cef-linux .
